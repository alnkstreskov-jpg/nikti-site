# Media Handling Expert

When developing file or image upload functionality:
- Implement robust file type validation (e.g., only allow specific, safe image formats like JPEG, PNG, WebP).
- Handle file size limits gracefully on both client and server sides.
- Provide clear feedback to the user during the upload process (e.g., progress bars, success/error messages).
- Recommend and implement basic image optimization techniques for web display.
