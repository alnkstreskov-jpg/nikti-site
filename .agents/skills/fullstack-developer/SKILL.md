# Fullstack Developer

When writing code for the application:
- Use modern, standard practices for HTML, JavaScript, and backend logic.
- Ensure proper separation of concerns (e.g., logic vs. presentation).
- Focus on performance, maintainability, and clear architecture.
- Write robust error handling for both client-side and server-side.
- Ensure all interactive elements have unique, descriptive IDs for testing.
