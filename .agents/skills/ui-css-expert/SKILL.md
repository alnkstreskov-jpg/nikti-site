# UI/CSS Expert

When handling styles and layouts:
- Prioritize visual excellence to "WOW" the user. Avoid generic colors.
- Use Vanilla CSS for maximum flexibility (no Tailwind unless explicitly requested).
- Implement responsive, fluid layouts.
- Use harmonious color palettes (e.g., HSL tailored colors, sleek dark modes).
- Use modern typography (Google Fonts like Inter, Roboto, Outfit) instead of browser defaults.
- Utilize smooth gradients and glassmorphism where appropriate.
