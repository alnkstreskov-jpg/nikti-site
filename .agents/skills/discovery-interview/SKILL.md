# Skill Discovery Interview

When triggered, follow this workflow to prevent hallucinated or incorrect work:
1. **Initial Intake:** Ask the user about the "What" and "Why" of the project/feature.
2. **Constraint Checking:** Probe for technical requirements, edge cases, security needs, and constraints.
3. **Synthesis:** Synthesize the answers into a clear specification or project plan before writing code.
4. **Adapt Dynamically:** Adjust the line of questioning based on the user's previous answers.
