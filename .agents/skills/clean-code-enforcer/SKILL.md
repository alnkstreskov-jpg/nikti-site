# Clean Code Enforcer

When writing or reviewing code:
- Keep the codebase concise, readable, and well-structured.
- Avoid unnecessary abstractions that complicate the logic.
- Use descriptive, intention-revealing variable and function names.
- Adhere strictly to the DRY (Don't Repeat Yourself) principle.
- Leave the code cleaner than you found it.
